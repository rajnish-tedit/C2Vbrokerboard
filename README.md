# C2V Broker Portal (prototype)

Interactive prototype of the Client2Vendor broker experience: registration wizard, sign in, forgot/reset password, first-time and with-data dashboards, and Agents management. All data is mock/demo.

- `index.html` — self-contained build; open directly or serve with GitHub Pages.
- `source/` — full Next.js 14 + Tailwind source. The single-file build is produced with `npx vite build --config vite.spa.config.mts` (output in `dist-spa/`).
